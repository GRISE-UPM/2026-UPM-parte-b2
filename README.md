# Sesión 1 - Parte B

Esta parte trabaja con la clase `CruiseControl`. Su especificación está en [`ESP-CruiseControlSpecification.pdf`](ESP-CruiseControlSpecification.pdf).

## Instrucciones

1. Realice un fork del repositorio <https://github.com/GRISE-UPM/2026-UPM-parte-b2>.
2. Clone en su ordenador el repositorio del que ha hecho el fork (el suyo, no el original).
3. Abra el proyecto en su entorno de desarrollo. El proyecto ya incluye JUnit y Mockito: no es necesario modificar el fichero `pom.xml`.
4. Lea la especificación: [`ESP-CruiseControlSpecification.pdf`](ESP-CruiseControlSpecification.pdf), que está en la raíz del repositorio.
5. El código de la clase `CruiseControl` ya está implementado y no debe modificarlo. Confeccione las pruebas de unidad usando JUnit, en la clase `CruiseControlTest` (`src/test/java/es/upm/grise/cruiseControl/CruiseControlTest.java`). Utilice Mockito si lo necesita.
6. Realice un commit. El mensaje debe ser significativo.
7. Realice un push al repositorio del que hizo el fork.
8. En GitHub, abra un pull request desde su fork hacia el repositorio original (`GRISE-UPM/2026-UPM-parte-b2`, rama `main`). Escriba su nombre y apellidos donde lo pide la plantilla del pull request.

## Normas

- Trabaje de forma individual.
- No utilice asistentes de inteligencia artificial (LLM) en esta sesión.
- No modifique ningún fichero de `src/main` ni el fichero `pom.xml`.
- Abra un único pull request al terminar esta parte y no realice más cambios después.
